# scrabble-dictionaries

Archive of [Scrabble](https://en.wikipedia.org/wiki/Scrabble) dictionaries in various languages.

All dictionaries are plain [UTF-8](https://en.wikipedia.org/wiki/UTF-8) text files with lists of words separated by [LF](https://en.wikipedia.org/wiki/Newline), sorted by Unicode code point (the order produced by `LC_ALL=C sort`). There is no trailing LF after the last word.

Used by [Scrabble Solver](https://scrabble-solver.org) ([kamilmielnik/scrabble-solver](https://github.com/kamilmielnik/scrabble-solver)).
