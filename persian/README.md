# Persian

## Persian to Persian dictionary

Headword list of the Moein Persian-to-Persian dictionary, taken from the [MansourM/persian-to-persian-dictionary](https://github.com/MansourM/persian-to-persian-dictionary) repository.

It is a general dictionary index rather than a curated word-game list. It contains:

- multi-word expressions, such as `آب انبار`
- dotted abbreviations, such as `آی. سی`
- single-letter entries
- a small number of entries with Arabic diacritics (tashkil)

- Download: [`persian.txt`](persian.txt)
- Source: https://github.com/MansourM/persian-to-persian-dictionary/blob/main/moein/words.txt
